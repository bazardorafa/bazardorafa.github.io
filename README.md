# Bazar do Rafa

Catálogo do bazar em memória do Rafael, com 13 anúncios revisados e galerias de fotos.

Publicado em https://bazardorafa.github.io pelo GitHub Pages, a partir da raiz da branch `main`.

Site estático, sem dependências ou etapa de compilação. Edite `index.html` para atualizar o conteúdo. Os preços de referência de produtos novos são estimativas informadas pela organização. Contato e retirada aguardam informações.
